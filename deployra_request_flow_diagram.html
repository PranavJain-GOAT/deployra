🔒 Security, Routing & Auth Middleware
12
⏱️ Rate Limiter
authLimiter: 30 req/15min/IP — all /auth/*
loginLimiter: 8 req/15min/IP — POST /login, /register
passwordResetLimiter: 5 req/hr/IP
emailResendLimiter: 3 req/hr/IP
On breach: Winston logs IP + path
standardHeaders: true (RFC 6585)
→ HTTP 429 Too Many Requests
13
🛣️ Express Router /api/v1/*
9 route files mounted in routes/index.js:
• /auth • /products • /users
• /payment • /uploads • /admin
• /purchases • /orders • /notifications
Matches HTTP method + URL path
14
✅ Joi Schema Validation
Runs before the controller.
registerSchema: name, email, password (min 8), role enum
loginSchema: email + password (required)
Returns field-level errors on failure
Controller never runs if invalid
→ HTTP 400 Bad Request
15
🔑 authenticate Middleware
1. Read req.cookies.accessToken
2. Fallback: Authorization: Bearer header
3. jwt.verify(token, JWT_SECRET) → decode
4. prisma.user.findUnique({id}) → confirm
5. req.user = user → next()
Guards all protected routes
→ HTTP 401 Unauthorized
16
🛡️ authorize / adminOnly (RBAC)
Role-based access via req.user.role
Enum roles: CLIENT • DEVELOPER • ADMIN
authorize('ADMIN','DEVELOPER')
→ checks role inclusion
adminOnly = authorize('ADMIN') shorthand
→ HTTP 403 Forbidden
Validated & authenticated request reaches controller
🎮 Controllers — Business Logic Layer
17
🔐 auth.controller.js
register: bcrypt.hash(pw,12) → prisma.user.create → sendVerificationEmail
login: bcrypt.compare → check lockedUntil → generateJWT pair → sha256(refresh) → prisma.refreshToken.create → Set-Cookie ✕2 → loginHistory
refresh: sha256 cookie → DB lookup → new accessToken
logout / logoutAll: revoke refreshToken(s)
googleCallback: Axios userinfo → prisma.upsert
18
